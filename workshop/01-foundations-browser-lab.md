# Foundations browser lab

## Goal

Move one focused documentation change through branch, commit, pull request, and review.

## Change

Add this sentence under the workshop change request in `docs/requirements.md`:

> Reviewers should confirm the due-date boundary behavior before accepting the change.

## Flow

1. Create a uniquely named branch.
2. Make only the requested change.
3. Commit with an intent-focused message.
4. Open a pull request that explains the problem and evidence.
5. Ask a partner to review the exact requirement change.
6. Check required status and security checks.
7. Do not merge unless the facilitator authorizes it.
